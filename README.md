# Наши планы 🎄 — Совместная заметка в стиле Apple Notes

Минималистичное веб-приложение для совместного планирования новогодних праздников с друзьями в реальном времени.

Сайт визуально и по поведению в точности повторяет приложение **«Заметки» (Apple Notes)** на iOS: один общий документ, тёплый фон, фирменный жёлтый акцент, интерактивные чек-листы, цветные курсоры участников и мгновенная CRDT-синхронизация.

- 🌐 **Сайт на GitHub Pages:** [https://ilyaflexer228.github.io/noites/](https://ilyaflexer228.github.io/noites/)
- 💻 **Репозиторий проекта:** [https://github.com/Ilyaflexer228/noites](https://github.com/Ilyaflexer228/noites)

## 🌟 Возможности и архитектура

- **В стиле Apple Notes**:
  - Светлая и тёмная темы оформления.
  - Нативная типографика iOS (SF Pro Text / Display).
  - Фирменные круглые чек-листы: при нажатии плавно заливаются жёлтым цветом, а текст зачёркивается.
  - Форматирование: Крупный заголовок (H1), Подзаголовок (H2), Обычный текст (Aa), Жирный (B), Курсив (I), Зачёркнутый (S), Маркированный и нумерованный списки.
  - Панель инструментов оптимизирована под экраны iPhone и Android с учётом виртуальной клавиатуры и Safe Areas.
- **Совместное редактирование в реальном времени (CRDT)**:
  - Бесконфликтное математическое слияние правок (RGA + Lamport Clocks + State Vectors).
  - Поддержка операций `text_update`: одновременное редактирование одной строки несколькими друзьями без потерь и перезаписи.
  - Положение курсора не сбрасывается при получении чужих изменений.
- **Офлайн-режим и локальная устойчивость (IndexedDB)**:
  - Мгновенная загрузка документа при открытии страницы.
  - Операции удаляются из локальной очереди **только после подтверждения сервером (op_ack)**. При сбоях сети unacknowledged правки сохраняются и синхронизируются при повторном подключении.
  - Защита от дублирования текста (идемпотентность).
- **Присутствие и живые курсоры (Awareness)**:
  - Выбор имени и эмодзи-аватара при первом входе (Илья 😎, Дима 🍻, Саша 🚀).
  - В шапке отображаются аватары всех друзей, находящихся онлайн.
  - В тексте видны цветные курсоры с именами друзей.
- **Безопасный доступ по ссылке-приглашению**:
  - Кнопка **«Поделиться»** копирует защищённую ссылку со случайным криптографически стойким токеном доступа.
  - Сервер проверяет токен приглашения (`inviteKey`) при каждом WebSocket-подключении. Посторонние не могут получить доступ к заметке.
  - Секретные ключи не хранятся в публичном репозитории.
- **Автоматическое сохранение с подтверждением сервера**:
  - Никаких кнопок «Сохранить».
  - Индикатор в шапке показывает честный статус: *«Сохранено»* (после подтверждения записи сервером), *«Синхронизация…»*, *«Офлайн (сохранено локально)»*, *«Ошибка доступа»*.
- **Экспорт заметки**:
  - Возможность в один клик скачать планы в **Markdown (.md)**, **HTML (.html)** или **Plain Text (.txt)**.

## 📁 Структура проекта

```
d:\noites/
├── index.html                   # Главная страница (Apple Notes UI)
├── styles.css                   # Стили iOS Notes (темы, шрифты, чек-листы, адаптивность)
├── config.js                    # Конфигурация (WS URL, безопасные токены, параметры документа)
├── js/
│   ├── app.js                   # Координатор приложения (профиль, темы, экспорт, модальные окна)
│   ├── editor.js                # Движок редактора (iOS форматирование, горячие клавиши, курсор)
│   ├── crdt.js                  # CRDT-движок (бесконфликтное слияние, часы Лампорта, text_update)
│   ├── storage.js               # Хранилище IndexedDB (очередь с гарантией доставки до op_ack)
│   ├── awareness.js             # Модуль присутствия друзей и живых цветных курсоров
│   └── sync.js                  # Сетевой клиент WebSocket (протокол Hocuspocus / Yjs)
├── server/
│   ├── server.mjs               # Node.js WebSocket CRDT сервер с постоянным хранилищем
│   ├── server_py.py             # Автономный Python WebSocket CRDT сервер (без доп. библиотек)
│   ├── package.json             # Зависимости сервера Node.js (ws, dotenv)
│   ├── Dockerfile               # Docker-контейнер для облачного развёртывания
│   └── .env.example             # Переменные окружения (PORT, INVITE_SECRET, DATA_DIR)
├── tests/
│   ├── test_full_suite.py       # Комплексный тест всех 12 сценариев поверх живого WebSocket
│   ├── test_crdt_scenarios.py   # Тест 10 сценариев CRDT-слияния
│   ├── test_server_protocol.py  # Тест серверной авторизации, op_ack и комнат
│   └── test_live_websocket.py   # Интеграционный тест WebSocket-подключения
├── .github/workflows/deploy.yml # Автоматический деплой на GitHub Pages
├── render.yaml                  # Конфигурация бесплатного деплоя на Render.com
├── fly.toml                     # Конфигурация деплоя на Fly.io
└── README.md                    # Документация и инструкции
```

## 🚀 Быстрый локальный запуск

### 1. Запуск WebSocket-сервера

#### Через Python 3 (работает «из коробки» без внешних зависимостей)
```powershell
python server\server_py.py
```

#### Через Node.js
```powershell
cd server
npm install
npm start
```

### 2. Открытие фронтенда в браузере
```powershell
python -m http.server 3000
```
Откройте в браузере: **`http://localhost:3000`**

## 🌐 Развёртывание (GitHub Pages + Облачный сервер)

### Шаг 1. Фронтенд на GitHub Pages
Фронтенд автоматически развёртывается через GitHub Actions:
👉 **`https://ilyaflexer228.github.io/noites/`**

### Шаг 2. WebSocket-сервер в облаке (Render.com / Fly.io / Railway)
1. Создайте Web Service на [Render.com](https://render.com) из репозитория `Ilyaflexer228/noites`.
2. Укажите:
   - **Root Directory**: `server`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Environment Variables**:
     - `PORT` = `10000`
     - `INVITE_SECRET` = `<любой случайный ключ или автогенерация>`
3. В параметрах ссылки или в `config.js` укажите ваш адрес: `?ws=wss://your-service.onrender.com`.
